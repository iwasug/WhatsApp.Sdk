<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host Stream → MediaCrypto | Untrusted plaintext bytes and metadata (mimetype, dimensions, caption) cross into the encrypt-then-MAC envelope here |
| mmg HTTP → MediaDownloader | Untrusted network bytes cross into verify-then-decrypt here; nothing is trusted before all three checks pass |
| Inbound Message proto → dispatcher branch | Adversary-influenced media fields (hashes, directPath, lengths) cross into field validation here |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Tampering | MediaCrypto + MediaDownloader (tampered blob delivered as valid) | high | mitigate | Verify-then-decrypt in fixed order (enc-hash, then 10-byte MAC with FixedTimeEquals, then plain-hash) with zero plaintext delivered on any failure; Baileys-style unverified streaming is never used; tamper vectors in the frozen fixtures gate every build |
| T-06-02 | Information Disclosure | Media paths (mediaKey/cipherKey/macKey, hashes, URLs in logs, events, exceptions) | medium | mitigate | ZeroMemory on every key temporary after use; no log call on media paths sees key/plaintext/ciphertext/hash/URL bytes; exceptions and events carry rule-only text plus metadata; tests assert via hash fingerprints never raw key output |
</threat_model>
