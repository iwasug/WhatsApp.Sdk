| T-2-08 | Tampering | QueryRouter id correlation | high | mitigate | 64-bit monotonic ids never reused while open; TCS removed on timeout with late arrivals discarded + debug-logged; closing fails fast so no query hangs; timeout is a typed exception (seed 2-seed-08) |
