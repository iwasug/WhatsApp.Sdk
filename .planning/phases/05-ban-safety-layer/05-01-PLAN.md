<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host → safety gate | Every public send must cross the gate; an ungated egress is a privilege escalation |
| gate → store registry | Safety state read/writes cross the host-owned store boundary (D-06 durable writes) |
| event emit → host handlers | Safety events are informational; handler exceptions are logged and swallowed |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Elevation of Privilege | Public send paths (all three) | high | mitigate | Single `ISafetyGate` chokepoint on every public send + `SendPathAuditTests` proof of zero ungated egress |
| T-05-02 | Tampering | `SafetyOptions` unsafe thresholds | high | mitigate | `SafetyOptions.Validate` rejects unsafe bounds unless `AllowUnsafeThroughput` is true |
| T-05-03 | Information Disclosure | Safety events leaking JID/payload | medium | mitigate | Rule-only messages; event fields exclude message bodies and key bytes |
| T-05-SC | Tampering | Package installs | high | mitigate | No new packages; build/test only |

*Threat-ID note: `T-05-SC` is the reserved phase-level supply-chain row kept in every plan of this phase; it is never among the regular `T-05-NN` IDs.*
